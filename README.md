# Life-in-the-Country
This is a 2D game that players have to live in on a island and develop it into a country area. the player has to farm crops and build the area in to a town
## how to play
USe the 
Arrow keys to move left, right, up, down
Use also:
A key - Move left
D key - right
S key - Down
W key - Up
Q key - to change Tool left
E key - to change Tool right
E key - to change type of crop to plant
Tab key - to open and close the diagnostics panel 
N key - to change to next day
